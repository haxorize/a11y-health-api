# Issue Template

Use this template for each GitHub issue created with `gh issue create`.

```markdown
## Parent feature spec

#<spec-issue-number>

## What to build

A concise description of this vertical slice. Describe the end-to-end behavior, not layer-by-layer implementation. Reference specific sections of the parent spec rather than duplicating content.

## Acceptance criteria

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Blocked by

- Blocked by #<issue-number> (if any)

Or "None - can start immediately" if no blockers.

## Parent spec criteria

Reference by number from the parent feature spec:

- Acceptance criterion 3
- Acceptance criterion 7
```
